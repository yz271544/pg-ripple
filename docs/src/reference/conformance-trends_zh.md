# 一致性趋势

存储库在 [`tests/conformance/history.csv`](https://github.com/trickle-labs/pg-ripple/blob/main/tests/conformance/history.csv) 中包含历史行。当前的 CI 不会附加到该文件，因此它绝不能被视为实时发布仪表板。

## 当前资格政策

| 套件 | 当前 CI 角色 | 证据 |
|---|---|---|
| W3C SPARQL 1.1 | 必需 | 所有 324 个锁定用例必须通过 |
| Apache Jena | 信息性 | 套件运行时的结果制品 |
| WatDiv | 执行门槛 | 空数据库上的 32 个检入模板；无规模或延迟声明 |
| LUBM | 必需 | 所有 14 个 OWL RL 查询必须通过 |
| OWL 2 RL | 仅必需源检查 | 固定的语料库下载和校验和；无当前一致性结果 |

使用评估的确切提交的制品。除非比较 URI 语料库、夹具、运行器和通过策略相同，否则不要跨线束修订比较百分比。

## 历史数据

`history.csv` 仍然有用作旧运行的出处。它不是当前基准测试产生器，也不能证明 v0.136.0 的状态。

要手动记录新行，首先运行相关套件，并将其原始报告与该行一起保留。
