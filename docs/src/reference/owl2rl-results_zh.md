# OWL 2 RL 源状态

pg_ripple 实现了 OWL 2 RL 规则，并具有各个推导行为的回归覆盖率。当前的 CI 作业不执行 W3C OWL 2 RL 一致性语料库。

## 当前 v0.136.0 证据

CI 下载固定的 W3C `all.rdf` 源，从 `tests/conformance/sources.lock` 验证其 SHA-256 校验和，解析 XML，并检查它是否包含 489 个 OWL 测试标识符。该语料库包含对 RL 配置文件的 91 个引用。

这是一个失败关闭的源采集检查。它证明预期的语料库可用且完整。它不会产生通过率。

```sh
bash scripts/fetch_conformance_tests.sh --owl2rl
```

历史测试装置期望每案例测试用例，并且如果不通过适配器就无法执行单体 `all.rdf` 源。在该适配器存在之前，该项目不声明当前版本的 OWL 2 RL 一致性百分比。
